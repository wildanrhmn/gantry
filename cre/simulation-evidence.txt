Captured 2026-09-13 18:45 UTC by: cre workflow simulate --target staging-settings --trigger-index 0 gantry-scoring

The confidential handler scores addresses inside the enclave. The thresholds that
decide a tier are fetched as a secret in the TEE and never leave it; the scoring
rules themselves are public in scoring.ts. The tier the enclave returns is what the
Uniswap v4 hook charges, so the confidential part is the product, not a placeholder.

Inputs read inside the enclave, both live:
  behaviour  https://api.studio.thegraph.com/query/1760064/gantry-mainnet/v0.0.2
             the mainnet subgraph, queried at run time
  traces     https://www.gantryhook.xyz/api/traces
             reverted attempts, read from the Substreams sink. A reverted transaction
             emits no logs, so this is the one input no subgraph can produce.
  secret     gantry_scoring_params  (tier thresholds, fetched with runtime.getSecrets)
